# Glossary

- **ABM:** agent-based model.
- **MAL:** project shorthand for multi-agent learning; not claimed as a
  standardized scientific model class.
- **Model pack:** versioned economic rules, schedules, parameters, and agent
  archetypes.
- **Scenario:** a model pack plus initial data, shock, policies, seeds, horizon,
  and requested metrics.
- **Reference mode:** deterministic, auditable execution with ordered
  reductions.
- **Fast mode:** optimized execution that must remain statistically equivalent
  within declared tolerance.
- **Fidelity class:** the validated relationship between a hardware/profile
  approximation and a higher-resolution reference.
- **Common random numbers:** the same exogenous random streams reused across
  policy branches to reduce comparison noise.
- **Conditional result:** an outcome that follows under the scenario's stated
  assumptions, not an unconditional prediction.
