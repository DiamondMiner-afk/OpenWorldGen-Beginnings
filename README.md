# OpenWorldGen

A local-first economic simulation and scenario research project.

**Alpha · 0.1.0 · GPL-3.0-only**

OpenWorldGen is being built to explore how households, businesses, finance,
institutions, and policy interact—and how those interactions can produce
unexpected outcomes. Its long-term goal is an evidence-backed agent economy
with heterogeneous behavior, learned policies, bounded LLM decisions, and
transparent comparisons against real-world outcomes.

**This alpha is a runnable research foundation, not a validated prediction
machine.** It does not provide a reliable ten-year economic forecast or
financial, investment, lending, or policy advice.

## What you can run today

Two separate workflows are available:

| Workflow | What it does | Current boundary |
| --- | --- | --- |
| Economic simulator | Runs households, firms, banks, government, a central bank, and a rest-of-world boundary; compares scenario and policy paths | Opening populations and balances are synthetic; most behavior uses explicit development rules |
| US forecasting experiment | Uses local Qwen to forecast GDP growth, unemployment, and CPI inflation from historical release-vintage data; overlays predictions, observations, persistence, and AR(1) | A separate exploratory benchmark, not forecasts generated by a calibrated US agent economy; requires externally obtained inputs |

The economic engine includes:

- Four sectors: energy, food, manufacturing, and services.
- Individual agent accounts, fixed-point money, double-entry settlement,
  borrowing, debt service, defaults, and bank resolution.
- Optional explicit credit contracts with bank and nonbank lenders.
- Ownership/legal-entity records and optional mutable scenario laws,
  institutional gates, and influence-group weights.
- Deterministic named random streams, policy branches, checkpoint/resume,
  accounting checks, and replay hashes.
- CSV/Parquet outputs and self-contained interactive HTML/SVG graphs.
- An experimental recorded firm-decision path with bounded cash transfers
  and exact-observation replay.

The governance system does **not** require corporate influence to dominate:
scenario-defined weights and rules can change. These are simplified model
institutions, not a complete implementation of real-world law.

## Quick start

### Requirements

- Rust **1.95.0**, as pinned in `rust-toolchain.toml`, with Cargo and a native
  compiler/linker.
- Python **3.13** for the optional SDK and the supported Python setup.
- A modern browser for the generated HTML graphs.

The basic simulation needs **no model weights, API key, GPU, or downloaded US
dataset**. Initial compilation may fetch Rust dependencies. Commands below
assume you are in this repository's root.

### Build and run a scenario

```bash
cargo build --locked --release -p owg-cli

cargo run --locked --release -p owg-cli -- validate \
  scenarios/v0.1/inflation_lab.yaml

cargo run --locked --release -p owg-cli -- run \
  scenarios/v0.1/inflation_lab.yaml \
  --branch baseline --replications 1 --end-month 48 \
  --output outputs/alpha-baseline

cargo run --locked --release -p owg-cli -- validate \
  outputs/alpha-baseline --kind result-bundle
```

Open `outputs/alpha-baseline/plots.html` in your browser. It works without a
web server. The graph shows a **synthetic scenario**, not observed US history.
Use a new output directory for each experiment.

### Run the end-to-end MVP

```bash
python3 scripts/run_mvp.py --output runs/my-alpha
```

This builds the debug CLI and runs a 120-month fictional economy with
96 households, 12 firms, two banks, three branches, and two replications.
It also checks checkpoint/resume equivalence, a scenario law change, and
recorded firm-decision replay. It uses a deterministic reference policy by
default, not an LLM.

For a smaller smoke run:

```bash
python3 scripts/run_mvp.py \
  --months 12 --replications 1 --output runs/my-alpha-smoke
```

Open `runs/my-alpha/economy/plots.html` for the full MVP's graphs.

### Compare policy branches

```bash
cargo run --locked --release -p owg-cli -- compare \
  scenarios/v0.1/inflation_lab.yaml \
  --replications 2 --output outputs/alpha-comparison
```

Two replications are a quick engineering demonstration, not sufficient
precision for substantive economic conclusions. The supplied scenario has
six branches; the MVP runner creates its own three-branch scenario.

## Outputs and reproducibility

A successful ordinary result bundle contains:

```text
bundle.json          File inventory and checksums
manifest.json        Run metadata and input/model/scenario hashes
metrics.csv          Inspectable time-series metrics
metrics.parquet      Columnar version of the metrics
plots.html           Interactive graphs
report.md            Generated run report
comparison.json      Policy-comparison diagnostics
mechanisms.json      Model mechanism summaries
accounting.json      Accounting diagnostics
journal_hashes.json  Financial audit hashes
event_audit.json     Scheduled-event and optional governance/credit audits
```

Accounting closure and deterministic replay are implementation checks.
They do not establish that a model matches the real economy. A mechanism
summary describes the model's behavior; it is not independent causal evidence.

## Optional local Qwen experiment

With `llama-server` installed separately and a compatible local GGUF available:

```bash
python3 scripts/run_mvp.py --llm \
  --model /absolute/path/to/your/model.gguf \
  --output runs/my-alpha-qwen
```

The runner starts its own loopback-only model server and stops it afterward.
The current executive can choose **retain cash or a bounded transfer to a
direct household owner**. It cannot yet independently set prices, hire
workers, invest, create shell companies, or evade taxes. This experimental
actor run is separate from the ordinary rule-driven simulation bundle.

Model weights are not distributed here. Check the model's own licence,
compatibility, and memory requirements. No trained RL policy or representative
runtime MatrAIx population is delivered in this alpha.

## Historical US predictions versus observations

Research code lives in `research/us-economy-2007-2023/code/`. The separate
Qwen pilot evaluates 15 origins from 2020Q1 through 2023Q3, producing 45
forecasts. Its graph overlays:

- **Observed next vintage:** the subsequent historical data snapshot's values.
- **Persistence:** the latest known value carried forward.
- **Expanding AR(1):** a relationship fitted to earlier released
  current/next-vintage value pairs.
- **Qwen:** numerical forecasts generated from supplied past indicator histories.

Dates and future target labels are withheld from Qwen's requests. However,
pretrained historical knowledge is uncontrolled, and the analyst has already
seen the episodes. This is **not a contamination-free or prospective blind
test**. Qwen's requested 80% intervals were poorly calibrated in the recorded
pilot; no model's superiority is established by that small experiment.

Cached source data, recorded model responses, and local result graphs are not
part of the minimal source release. Running this workflow requires preparing
those inputs separately. See the [MVP runbook](docs/MVP.md) for commands and
prerequisites. A localhost preview URL from a developer session is not a public
demo.

## Python SDK

The optional SDK wraps the same Rust CLI. Its current package supports
Python 3.13:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -e ./python
```

The environment commands above use POSIX paths. On Windows, use the
corresponding `.venv\\Scripts\\python.exe` path.

Set `OWG_BIN` to your built `owg` executable if it is not on `PATH`.
See the [SDK README](python/README.md) for examples.

cargo fmt --all --check

cargo test --locked --workspace --all-targets

python3 -m unittest discover -s scripts -p 'test_run_mvp.py'

## Alpha limitations and direction

Still open: balanced measured US initialization and calibration; richer
supplier networks, housing, securities, ownership and tax mechanisms;
validated heterogeneous/persona behavior; trained multi-agent RL; broader
strategic LLM actions; political enforcement and institutional change;
international finance/trade; and the Minecraft Fabric edition.

The engine currently uses explicit behavioral rules for much of the economy.
RL, personas, and LLMs are a development direction—not an already completed
replacement. A ten-year scenario can run; a defensible ten-year forecast
requires substantially more evidence.

Start with the [implementation status](docs/IMPLEMENTATION_STATUS.md),
[model card](docs/MODEL_CARD_v0.1.md), [scientific charter](docs/SCIENTIFIC_CHARTER.md),
and [delivery gates](docs/GATES.md). Some research notes describe older
checkpoints; the current alpha scope is summarized here and in the MVP runbook.

## Contributing and releasing

For bug reports, include the command, scenario, OS/toolchain, error output,
and a minimal reproducible example. Do not attach credentials, private
financial data, or model weights.

Before uploading, follow the [alpha source-release checklist](docs/ALPHA_RELEASE.md).
Keep generated runs, downloaded datasets, model weights, caches, local
environments, and deprecated repositories out of the source release.
Nothing in this README publishes a GitHub repository or creates a release.
